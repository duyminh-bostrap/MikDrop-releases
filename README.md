# MikDrop releases

Bản dựng sẵn của [MikDrop](https://github.com/duyminh-bostrap/MikDrop): chia sẻ ảnh và tệp ngang hàng (P2P) giữa iPhone, Android, Mac, Windows và Linux qua Wi-Fi, chỉ cần trình duyệt.

Prebuilt binaries of [MikDrop](https://github.com/duyminh-bostrap/MikDrop): peer-to-peer file sharing between iPhone, Android, Mac, Windows and Linux over Wi-Fi, right in the browser.

## Tải về / Download

Vào [Releases](https://github.com/duyminh-bostrap/MikDrop-releases/releases/latest) và chọn file cho hệ điều hành của bạn (không cần cài Node.js):

| File | Hệ điều hành |
|---|---|
| `MikDrop.exe` | Windows 64-bit |
| `mikdrop-linux-x64` | Linux x64 (`chmod +x` rồi chạy) |
| `mikdrop-linux-arm64` | Linux ARM64, ví dụ Raspberry Pi |
| `SHA256SUMS.txt` | Mã kiểm tra SHA-256 |

Mã nguồn, hướng dẫn sử dụng và báo lỗi nằm ở repo chính: https://github.com/duyminh-bostrap/MikDrop

Các release ở đây được đồng bộ từ repo chính.
